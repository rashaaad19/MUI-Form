# MUI Form (React and Material UI)

> **Training exercise.** This repository was built as practice during the *Frontend and Mobile Cross-Platform Training* at the **Information Technology Institute (ITI), Port Said** (03/2025 – 08/2025). It is a small learning exercise, not a production application.

A form built with **React** and **Material UI (MUI)** to practice the component library.

## Tech Stack

| Area | Technology |
| --- | --- |
| Framework | React |
| UI library | Material UI (MUI) |

## Getting Started

```bash
git clone https://github.com/rashaaad19/MUI-Form.git
cd MUI-Form
npm install
npm start   # or npm run dev, depending on the setup
```

## What I Learned

- Building form layouts with MUI input components
